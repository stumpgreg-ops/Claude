# “The Lotus Eaters”: teacher's annotated model (9.RL.1.A)

Grade 9 · Unit 2 · Lesson 3 (Challenge Accepted!) · *The Odyssey*, textbook p. 721. Same format as the Circe annotated model.

| File | What it is |
|---|---|
| `Odyssey-LotusEaters-Annotated-Model.html` | One self-contained page (fonts built in) for Canvas or a browser. |
| `Odyssey-LotusEaters-Annotated-Model.pdf` | The same six sheets printed with every annotation showing. |

**Standards.** Aligned with the Cyclops model (Lesson 4): 9.DSR, 9.RV.1.B, 9.RL.1.A, 9.RL.2.B and 9.W.1.C, plus 9.RL.3.B for the lesson's setting focus. Setting notes are split: 9.RL.3.B where the setting drives the plot or shapes a character (the storm, nine days adrift, the Lotus changing the scouts), 9.RL.1.A where it builds a theme (the calm island).

**Sheets.** 1: annotation key ("I can" learning targets, EQ, legend, topic vs. theme, citing by line number, the lesson's student codes). 2–4: the passage, lines 1–8, 9–17 and 18–27, with the four numbered themes at the top of the first. 5: Write About It (summary, theme with a line citation, exit ticket). 6: teacher notes (how the themes develop, the slide-note discussion key, a model response, things to watch for).

**Colours.** Purple = vocabulary and figurative language (blue notes with the context clue, 9.RV.1.B); yellow = theme (red notes, 9.RL.1.A); green = character, setting or plot (red notes, 9.RL.1.A or 9.RL.3.B); orange = word choice, tone and voice (purple notes, 9.RL.2.B). Each red note's number is the theme it develops. On top of the colours are the lesson's student codes: a pink underline where Odysseus acts as a hero or leader, a red circle around each major event, and a star in the margin beside a line the note clarifies. Each note ends with its SOL code.

**On screen.** Click a passage sheet to reveal its highlights one at a time; each brings its handwritten note and arrow. After the last one a click clears the sheet; Shift-click, Backspace or ← goes back one. Printing shows everything.
