How this works (3 steps)
  1. Students: in the game, tap My progress code (on the title screen or after a level), tap Copy code, and paste the code into your Canvas assignment “{{ASSIGNMENT}}” (Submission type: Text Entry).
  2. You: either copy codes from SpeedGrader and paste them in box 2 below (you can type the student's name first, like Ann Smith: SOL1-…), or on the assignment page click Download Submissions and drop that .zip file on box 2.
  3. Read the table. Change the goals in box 1 and every suggested grade updates. Download or copy the table, then enter the grades in Canvas.

Everything stays in this browser: this page sends nothing anywhere. Each code shows everything a student has done on one Chromebook up to the moment the code was made, so ask for a new code whenever you grade.
